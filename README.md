# Кредитный скоринг - байесовский классификатор

Gaussian Naive Bayes для предсказания кредитногориска заемщика на датасете german_credit_data (1000 заявок).

## Задача
Предсказать, относится ли заемщик к категории good (надежный) или bad (рискованный) на основе демографических и финансовых признаков: возраст, тип занятости, жилье, состояние сберегательного и расчетного счета, сумма и срок кредита, цель кредита.

## Подход
1. Пропуски в Saving accounts/Checking account обработаны как отдельная категория "none" - отсутствие счета само по себе значимый сигнал в задаче скоринга, а не недостающие данные.
2. Категориальные признаки закодированы One-Hot Encoding, обучена baseline модель GaussianNB.
3. Применен отбор признаков SelectKBest(chi2) с отбором топ-5 наиболее информативных признаков, модель переучена.
4. Baseline и модель после отбора признаков сравниваются с акцентом на recall по классу bad - именно ошибка "пропустить рискованного заемщика" дороже для банка, чем отказать надежному.

 ## Результаты
 | Метрика | Baseline (все признаки) | После отбора (top-5, chi²) |
|---|---|---|
| Accuracy | 0.67 | **0.72** |
| Precision (bad) | 0.44 | **0.52** |
| Recall (bad) | 0.47 | **0.54** |
| F1 (bad) | 0.46 | **0.53** |
Отбор признаков улучшил не только общую точность, но и recall по проблемному классу bad - модель стала пропускать меньше рискованных заемщиков.

## Выводы и ограничения
Небольшой размер выборки, состоящий из 1000 записей влияет на то, что результат чувствителен к разбивке на train/test.
Дисбаланс классов (70 good/30 bad) занижает recall по миноритарному классу.
Предположение GaussianNB о независимости признаков нарушено (Credit amount и Duration коррелируют), что ограничивает потолок качества модели.
