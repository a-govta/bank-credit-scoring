# Кредитный скоринг - байесовский классификатор

Проект по прогнозированию кредитного риска заемщиков с использованием алгоритма Gaussian Naive Bayes на датасете german_credit_data, содержащем 1000 заявок на кредит.

## Задача

Цель проекта - предсказать, относится ли заемщик к категории:

good - надежный заемщик;
bad - рискованный заемщик.

Для прогнозирования используются демографические и финансовые характеристики клиента:

возраст;
тип занятости;
жилье;
состояние сберегательного счета;
состояние расчетного счета;
сумма кредита;
срок кредита;
цель кредита.

Для банка важно правильно оценивать кредитный риск клиента. Особое внимание в проекте уделяется классу bad, поскольку ошибка, при которой рискованный заемщик определяется как надежный, потенциально может привести к финансовым потерям банка.

## Данные

В проекте используется датасет german_credit_data, содержащий 1000 заявок на кредит.
Целевая переменная - Risk.
Распределение классов:
good - 70% 
bad - 30%
Таким образом, классы распределены неравномерно, поэтому при оценке модели важно учитывать показатели для класса bad.

## Подход
В проекте выполнены следующие этапы:
1. Категориальные признаки преобразованы с помощью One-Hot Encoding.
2. Обучена базовая модель Gaussian Naive Bayes.
3. Для обора признаков использован SelectKBest с критерием chi2.
4. С помощью SelectKBest и критерия chi2 выбраны 5 признаков из закодированного набора.
5. Модель обучена повторно после отбора признаков.
6. Результаты двух вариантов модели сравнены между собой.

## Используемая модель
В качестве основного алгоритма используется Gaussian Naive Bayes. Это вероятностный алгоритм классификации, основанный на теореме Байеса. В проекте он используется для определения того, относится ли заемщик к классу good или bad.

## Оценка модели
Для сравнения моделей используются следующие метрики:
Accuracy - доля правильных предсказаний модели среди всех наблюдений.
Precision - показывает, какая доля объектов, отнесенных моделью к классу bad, действительно относится к этому классу.
Recall - показывает, какую долю всех реальных рискованных заемщиков модель смогла обнаружить.
F1-score - объединяет Precision и Recall и позволяет оценить баланс между ними.
В задаче особое внимание уделено recall класса bad, поскольку важно не пропускать рискованных заемщиков.

## Результаты
| Метрика | Baseline (все признаки) | После отбора (top-5, chi2) |
|---|---|---|
| Accuracy | 0.67 | **0.72** |
| Precision (bad) | 0.44 | **0.52** |
| Recall (bad) | 0.47 | **0.54** |
| F1 (bad) | 0.46 | **0.53** |

После отбора признаков значения всех представленных метрик увеличились. Accuracy увеличилась с 0.67 до 0.72, а Recall класса bad - с 0.47 до 0.54; что означает правильное моделью обнаружение большой доли заемщиков из класса bad после отбора признаков.

## Выводы
В ходе проекта была построена модель Gaussian Naive Bayes для прогнозирования кредитного риска. Сравнение показало, что использование отбора признаков SelectKBest(chi2) в данном эксперименте улучшило показатели модели. Особенно важно увеличение Recall для класса bad с 0.47 до 0.54, так как для кредитного скорого обнаружение рискованных заемщиков является важной задачей.

## Ограничения проекта
У проекта есть несколько ограничений:
небольшой размер выборки - 1000 записей;
дисбаланс классов: 70% good и 30% bad;
результаты чувствительны к конкретному разделению данных на train и test;
Gaussian Naive Bayes предполагает независимость признаков, которая в реальных данных может не выполняться;
в данных присутствует зависимость между некоторыми признаками, например Сredit amount и Duration.
